
---

## Setup & Commands

1. **Install Dependencies:**
   ```
   cd ea2_group_project
   npm install
   ```

2. **Transpile TypeScript to JavaScript:**
   ```
   npm run build
   ```

3. **Start Live Server:**
   ```
   npm run start
   ```
