---

## Setup & Commands

### 1. Install Dependencies

```bash
npm install
```

### 2. Transpile TypeScript to JavaScript

```bash
npm run build
```

This transpiles `script.ts` into `script.js`.

### 3. Start Live Server

```bash
npm run start
```

Open `index.html` using the configured live server to view the project.
